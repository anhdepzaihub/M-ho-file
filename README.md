# 🔐 Mã xác nhận trực tuyến

Công cụ tạo **mã xác nhận OTP 6 chữ số** ngẫu nhiên, chạy hoàn toàn trên trình duyệt, kèm **kiểm tra kết nối mạng và phản hồi server**.

## ✨ Tính năng

- 🎲 Sinh mã OTP 6 số bằng `crypto.getRandomValues` (bảo mật)
- ⏳ Đếm ngược hiệu lực 60 giây, tự hủy mã khi hết hạn
- 🌐 Phát hiện Online / Offline theo thời gian thực
- 📡 Kiểm tra phản hồi server (timeout 4s)
- 🔄 Tự động thử lại mỗi 3 giây khi mất mạng
- 📋 Sao chép mã bằng 1 click
- 📱 Responsive, dùng được trên mobile

## 🚀 Sử dụng

### Cách 1: Mở trực tiếp trên GitHub Pages

👉 **Link demo:** `https://<USERNAME>.github.io/<REPO>/`

### Cách 2: Chạy offline

Tải file `index.html` về máy → double-click để mở bằng trình duyệt.
